| Device | How |
|---|---|
| **Mac** (Apple silicon, M1 or newer) | [Download for Mac](https://github.com/whisz12/Recall/releases/latest/download/Recall-mac.zip), unzip, drag to Applications. [Step-by-step guide →](https://whisz12.github.io/Recall/download.html#install) |
| **Windows** 10 / 11 | [Download for Windows](https://github.com/whisz12/Recall/releases/latest/download/Recall-windows.zip), extract, run `Recall.exe`. [Step-by-step guide →](https://whisz12.github.io/Recall/download.html#install) |
| **iPad / iPhone** | Open [whisz12.github.io/Recall](https://whisz12.github.io/Recall/) in Safari → Share → **Add to Home Screen** |
| **Android** | Open [whisz12.github.io/Recall](https://whisz12.github.io/Recall/) in Chrome → ⋮ → **Install app** |
| **Anything else** | Use it in the browser at [whisz12.github.io/Recall](https://whisz12.github.io/Recall/) |

The first time you open the desktop app, macOS or Windows asks you to confirm because Recall isn't from an app store. The [download page](https://whisz12.github.io/Recall/download.html#install) walks through it.
